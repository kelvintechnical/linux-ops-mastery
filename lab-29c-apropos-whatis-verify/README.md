## Concept: `/var/cache/man` Drives Keyword Search

- `whatis` and `apropos` depend on the indexed entries generated by `mandb`.
- Cache drift or deletion can break search behavior even when man pages exist.
- Verification requires both **artifact checks** (journal files) and **live checks** (post-rebuild queries).

## Task 1 — Audit whatis/apropos evidence from journals

### Purpose

Validate that prior labs actually produced searchable-doc evidence and trap coverage.

### Main command block

```bash
TASKLOG=/tmp/lab29c/task1.txt

echo "═══ Part A: required journal files present and non-empty ═══"      2>&1 | tee "$TASKLOG"
REQUIRED=(
  /root/rhcsa_journal/lab-29a/task1/whatis-grep.txt
  /root/rhcsa_journal/lab-29a/task1/apropos-list-directory.txt
  /root/rhcsa_journal/lab-29a/task2/mandb-rebuild.txt
  /root/rhcsa_journal/lab-29b/task2/task2-assertions.txt
)
MISSING=0
for f in "${REQUIRED[@]}"; do
  if test -s "$f"; then
    echo "✅ $f"
  else
    echo "❌ missing/empty: $f"
    MISSING=$((MISSING+1))
  fi
done | tee -a "$TASKLOG"
echo "missing_count=${MISSING}" | tee -a "$TASKLOG"

echo "═══ Part B: semantic checks in evidence ═══"                       | tee -a "$TASKLOG"
grep -Ei 'grep' /root/rhcsa_journal/lab-29a/task1/whatis-grep.txt       | tee -a "$TASKLOG"
grep -Ei 'list|directory|ls' /root/rhcsa_journal/lab-29a/task1/apropos-list-directory.txt | tee -a "$TASKLOG"
grep -E  'apropos_lines=' /root/rhcsa_journal/lab-29b/task2/task2-assertions.txt | tee -a "$TASKLOG"
grep -E  'whatis_lines='  /root/rhcsa_journal/lab-29b/task2/task2-assertions.txt | tee -a "$TASKLOG"

echo "═══ Part C: live sanity check from current host ═══"               | tee -a "$TASKLOG"
whatis grep                     2>&1 | tee -a "$TASKLOG"
apropos 'list directory'        2>&1 | tee -a "$TASKLOG"

echo "═══ Part D: Tier B audit capture as lab user ═══"                  | tee -a "$TASKLOG"
sudo -u "${USER}" bash -c "whatis grep > '${USER_HOME}/whatis-asuser-audit.txt'"
sudo -u "${USER}" bash -c "apropos 'list directory' > '${USER_HOME}/apropos-asuser-audit.txt'"
stat -c '%U:%G %a %n' "${USER_HOME}/whatis-asuser-audit.txt" "${USER_HOME}/apropos-asuser-audit.txt" | tee -a "$TASKLOG"
wc -l "${USER_HOME}/whatis-asuser-audit.txt" "${USER_HOME}/apropos-asuser-audit.txt" | tee -a "$TASKLOG"

echo "exit was: $?" | tee -a "$TASKLOG"
```

## Task 2 — Destroy-restore: wipe man cache, rebuild, and re-test

### Purpose

Rehearse T41 and T29-A together by intentionally breaking index state and restoring it.

### Main command block

```bash
TASKLOG=/tmp/lab29c/task2.txt

echo "═══ Part A: baseline query counts ═══"                             2>&1 | tee "$TASKLOG"
B_WHATIS=$(whatis grep 2>/dev/null | wc -l)
B_APROPOS=$(apropos 'list directory' 2>/dev/null | wc -l)
echo "baseline whatis count=${B_WHATIS}"                                 | tee -a "$TASKLOG"
echo "baseline apropos count=${B_APROPOS}"                               | tee -a "$TASKLOG"

echo "═══ Part B: destroy man cache (T41 drill) ═══"                     | tee -a "$TASKLOG"
rm -rf /var/cache/man/*
find /var/cache/man -maxdepth 2 -type f | head -n 5                      | tee -a "$TASKLOG"

echo "═══ Part C: query while cache is wiped (expected degraded/empty) ═══" | tee -a "$TASKLOG"
D_WHATIS=$(whatis grep 2>/dev/null | wc -l)
D_APROPOS=$(apropos 'list directory' 2>/dev/null | wc -l)
echo "degraded whatis count=${D_WHATIS}"                                 | tee -a "$TASKLOG"
echo "degraded apropos count=${D_APROPOS}"                               | tee -a "$TASKLOG"

echo "═══ Part D: restore by rebuilding index ═══"                       | tee -a "$TASKLOG"
mandb -c                                                                  2>&1 | tee /tmp/lab29c/mandb-restore.txt | tee -a "$TASKLOG"

echo "═══ Part E: post-restore re-test ═══"                              | tee -a "$TASKLOG"
R_WHATIS=$(whatis grep 2>/dev/null | wc -l)
R_APROPOS=$(apropos 'list directory' 2>/dev/null | wc -l)
echo "restored whatis count=${R_WHATIS}"                                 | tee -a "$TASKLOG"
echo "restored apropos count=${R_APROPOS}"                               | tee -a "$TASKLOG"

test "${R_APROPOS}" -gt 0 \
  && echo "✅ T29-A covered: apropos >0 after mandb rebuild" \
  || echo "❌ restore incomplete: apropos still empty"                    | tee -a "$TASKLOG"

test "${R_WHATIS}" -ge "${D_WHATIS}" \
  && echo "✅ whatis recovered after cache rebuild" \
  || echo "❌ whatis did not recover as expected"                         | tee -a "$TASKLOG"

echo "═══ Part F: Tier B post-restore query copy ═══"                    | tee -a "$TASKLOG"
sudo -u "${USER}" bash -c "apropos 'list directory' > '${USER_HOME}/apropos-post-restore.txt'"
stat -c '%U:%G %a %n' "${USER_HOME}/apropos-post-restore.txt"            | tee -a "$TASKLOG"
wc -l "${USER_HOME}/apropos-post-restore.txt"                            | tee -a "$TASKLOG"

echo "exit was: $?"                                                       | tee -a "$TASKLOG"
```

### Concept Card

| Concept | What it does |
|---|---|
| Cache destroy phase | Intentionally reproduces bad-state conditions |
| `mandb -c` restore phase | Recreates index from current man-page data |
| Before/degraded/restored counts | Quantifies forward recovery |
| **🪤 Trap Risk T41** | Skip destroy-restore drill and you never validate recovery muscle |
| **🪤 Trap Risk T29-A** | Empty `whatis`/`apropos` results can be index state, not missing commands |
